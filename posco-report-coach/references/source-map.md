# 원칙과 교재 출처

이 파일은 판단 원칙의 근거를 확인하는 지도다. 교재 전체를 복제하거나 원문의 모든 조언을 의무 규칙으로 전환한 문서가 아니다.

## 원자료

- 파일명: `201123_[청년 AI-Big Data 아카데미]_5_Big Data 보고서 작성 교안(20년, 김두환).pdf`
- 연도·저자: 파일명에 표시된 2020년(`20년`), 김두환. 별도의 서지 확인으로 보강한 정보는 아니다.
- 분량: 75쪽. 아래 `p.`는 PDF 파일의 1부터 시작하는 페이지 번호다.
- 구성: p.1–40 보고서 개념·작성 흐름, p.41–74 문장·시각 표현 실무, p.75 Q&A 종결 슬라이드.
- 적용 방식: 원리를 실행 가능한 AI 판단 기준으로 요약했다. 원문 PDF·페이지 이미지·장문 인용은 배포물에 포함하지 않는다.
- 출처 표시는 권리 허락을 대신하지 않는다. 이 스킬을 포스코가 공식 인증한 표준으로 소개하지 않는다.

## 맥락적 조언의 재해석과 제외

교재에는 특정 조직·문서 형식·교육 시점의 경험적 조언이 포함되어 있다. 아래 항목은 보편적 사실이나 자동 감점 기준으로 사용하지 않는다.

| 교재의 조언 또는 사례 | 근거 페이지 | 채택 범위 또는 재해석 |
|---|---|---|
| 상사의 사고와 선호 표현 반영 | p.8, 11–12 | 확인된 독자 특성에 맞춘다. 반대 근거·위험을 숨기거나 판단자의 생각을 임의 추정하지 않는다. |
| 상사의 예상 결론을 뒷받침할 자료 수집 | p.14 | 결론을 검증할 가설로 취급한다. 반증·대안 설명·불리한 증거도 검토한다. |
| 실행 불가능한 현장의견 배제 | p.16 | 실행 가능성 판단의 근거를 제시한다. 소수 의견이라는 이유로 중요한 위험 신호를 버리지 않는다. |
| 공포감 조성·강한 압박을 통한 몰입 | p.19 | 스킬 규칙에서 제외한다. 빠른 초안과 반복 수정이라는 작업 방식만 취한다. |
| 두괄식과 헤드라인 줄 수 | p.20, 23 | 결론 우선을 기본 제안으로 삼되 독자의 사전지식·논쟁성·매체에 맞춘다. 줄 수를 획일 적용하지 않는다. |
| 한 장 구성 원칙의 빈칸 | p.24 | `One slide One (빈칸)`의 미제공 답을 추정하지 않는다. 한 장의 논점과 근거가 일관되는지만 판단한다. |
| 시각 판단 비중·좌우뇌 기억 용량 수치 | p.27 | 검증되지 않은 수치를 과학적 근거로 재사용하지 않는다. 탐색과 이해를 돕는 시각화 원칙만 채택한다. |
| 핵심 위치·이미지 좌측 배치·구도 | p.29–30, 74 | 읽기 순서와 강조의 명확성을 평가한다. 모든 문서에 특정 좌표·방향·대칭을 강제하지 않는다. |
| 12–15줄·약 30% 여백 | p.31 | 해당 교재의 참고치다. 매체·페이지 크기·정보 밀도에 따라 조절하며 자동 감점하지 않는다. |
| Takeaway box의 제한적 용도 | p.34 | 기존 회사 양식에서 요약·시사점 등 다른 역할을 부여했다면 그 역할과 전체 흐름을 존중한다. |
| 사실만 있는 장은 부록으로 이동 | p.47 | 현황 공유·정보 제공이 목적이면 사실 자체가 본문의 핵심이 될 수 있다. |
| 동의어 활용과 반복어 제거 | p.44, 48, 50 | 핵심 개념·고유명사·기술 용어는 일관성을 우선한다. 문장 구조를 바꿔 불필요한 반복을 줄인다. |
| 특정 어미 제거·미래형 압축 | p.49, 53 | 의미가 유지될 때만 줄인다. 가능성·조건·전망을 확정 사실로 바꾸지 않는다. |
| 영문 단위의 소문자 사용 | p.50 | 기계적으로 소문자화하지 않는다. 공식 단위 표기와 원자료의 정의를 따른다. |
| 불명확한 출처는 수동문·항상 긍정문 | p.51 | 출처 불명확성은 표시한다. 부정을 줄이더라도 불가능 조건·제약·위험을 삭제하거나 약속을 추가하지 않는다. |
| 특정 글꼴·원색 금지·3색·선 굵기 | p.54–60 | 시각적 일관성의 예시로 사용한다. 조직 양식·가독성·의미 전달에 맞추며 취향 차이를 오류로 판정하지 않는다. |
| 축·눈금선 삭제와 차이 강조용 축 조정 | p.65, 68–69 | 이해에 필요한 축·단위·기준을 유지한다. 시각적 차이를 과장하는 축 조정은 적용하지 않는다. |
| 차트별 항목 수·꾸밈 방식 | p.67–71 | 데이터와 전달 목적에 맞춰 선택한다. 항목 수만으로 차트 적합성을 확정하지 않는다. |
| PNG·이미지 크기·검색 사이트 설명 | p.72–74 | 파일 형식만으로 투명도를, 픽셀 수만으로 품질을 단정하지 않는다. 사용 권한·해상도·실제 배경을 확인한다. |

## AI 사용을 위한 별도 보완

다음은 교재의 문장을 옮긴 원칙이 아니라, 업로드 문서·이미지를 AI가 다루기 위해 추가한 운영 기준이다.

- **원문 위치 추적**: 지적과 수정안을 원문 페이지·슬라이드·문단·영역에 연결한다. 관찰 사실과 제안을 구분한다.
- **OCR 불확실성**: 판독이 불명확한 글자·수치·단위를 추정해 확정하지 않는다. 문서 이미지의 일부만 제공되었다면 전체 맥락을 확인한 것처럼 말하지 않는다.
- **수치와 의미 보존**: 요약·교정·재배치·이미지 생성 전후에 수치, 단위, 날짜, 고유명사, 조건, 확실성 수준을 대조한다. 누락된 정보는 만들어 넣지 않는다.
- **접근성**: 색만으로 의미를 구분하지 않으며 대비·작은 글씨·범례·출력 크기를 검토한다. 검증되지 않은 정확한 색 대비 비율을 보고하지 않는다.
- **그래프 왜곡 방지**: 축·기준점·기간·분모·단위·이중축을 확인한다. 가독성 개선이 데이터 차이를 과장하거나 비교 조건을 바꾸지 않게 한다.
- **생성 이미지의 한계 표시**: 개선 모습을 보여 주는 이미지는 검토용 시안으로 취급한다. 사실·정확한 수치·문구의 최종 확인은 텍스트 또는 편집 가능한 원본을 기준으로 한다.

스킬의 피드백에서 위 보완을 사용할 때는 교재에 직접 적혀 있는 내용으로 귀속하지 않는다.
