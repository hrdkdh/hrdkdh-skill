# 문서와 이미지의 시각 검수

## 적용 원칙과 근거

- 목적은 독자가 핵심과 근거를 빠르게 읽도록 하는 것이다. 장식의 양이나 취향을 점수화하지 않는다.
- **교재 기반**: 원본 PDF p.26, 29–34, 54–74의 글머리표, 구조화, 정렬, 색, 도형, 표, 그래프, 이미지 원칙을 재구성했다.
- **AI 적용 보완**: 관측 한계, 접근성, 데이터 왜곡 방지와 검수 우선순위는 이 스킬에서 추가한 판단 기준이다. 교재의 직접 주장으로 설명하지 않는다.
- 원본의 수치·회사명·단위·기간·조건·출처는 보존한다. 디자인을 위해 근거를 지우거나 결론의 강도를 높이지 않는다.
- 사용자의 지정 양식과 조직의 현행 템플릿을 먼저 적용한다. 2020년 교재의 글꼴·CI 색 예시를 현행 회사 규정으로 단정하지 않는다.

## 1. 입력에 따라 확인 가능한 범위를 정한다

**AI 적용 보완**

| 입력 | 확인할 수 있는 것 | 단정하지 않을 것 |
|---|---|---|
| 편집 가능한 문서 | 문단·도형·표 속성, 실제 서체·크기·색, 데이터·차트 설정을 읽을 수 있는 범위 | 파일 속성을 읽지 않고 추정한 정확한 값 |
| 텍스트가 있는 PDF | 추출된 글과 실제 렌더링의 대응, 줄바꿈·배치·잘림·시각적 일관성 | 추출 순서가 곧 읽기 순서라는 가정, 확인하지 않은 원본 편집 속성 |
| 스캔·사진·스크린샷 | 보이는 글·숫자, 상대적 크기·정렬·간격·대비, 촬영에 포함된 부분 | 정확한 pt·RGB·여백 치수·글꼴명, 보이지 않는 페이지·범례·출처 |

1. 파일을 읽은 범위와 실제 이미지로 확인한 페이지를 구분한다. 일부 페이지만 보았다면 전체 문서 검수라고 하지 않는다.
2. 문서 이미지는 페이지 방향, 기울어짐, 잘린 가장자리, 흐림, 반사, 축소 여부부터 확인한다.
3. OCR 결과는 원본 화면과 대조한다. 특히 소수점, 쉼표, 음수, %, 단위, 기간, 표의 행·열 대응을 확인한다.
4. 읽히지 않는 내용은 `[판독 불가]`, 추정한 해석은 `[추정]`으로 표시한다. 숫자나 문장을 자연스럽게 채워 넣지 않는다.
5. 이미지에서 글씨가 작아 보이면 “본문 대비 보조 설명이 작아 축소 시 읽기 어렵다”처럼 상대적으로 진단한다.
6. 정확한 크기가 필요한 수정에는 “원본 속성 확인 후 본문보다 한 단계 크게” 등 적용 방법을 제시한다.
7. 내용만 제공되었다면 구조·표현 검수는 진행하되, 실제 정렬·잘림·대비 검수는 확인 불가로 남긴다.

## 2. 레이아웃·위계·표현을 검수한다

**교재 기반 판단 기준**

| 항목 | 문제를 판단하는 관찰 | 바로 적용할 수정 | 근거 |
|---|---|---|---|
| 읽기 순서 | 제목·핵심·근거의 순서가 모호하거나 시선이 여러 곳에 분산됨 | 핵심 메시지를 먼저 읽히게 하고 근거를 가까이에 배치한다. 도해와 설명의 순서를 맞춘다. | p.29–30 |
| 정보 위계 | 서로 다른 수준의 내용이 같은 크기·글머리표·박스에 놓임 | 상위 주장과 하위 근거를 나누고 같은 수준에는 같은 형식을 쓴다. | p.26, 32–33 |
| 글머리표 | 한 항목에 독립 주제가 섞이거나 인과관계를 병렬 항목으로 표시함 | 한 항목에 한 주제를 두고 원인·결과는 문장 또는 의미가 명확한 연결로 표현한다. | p.26 |
| 구조화 | 긴 글의 관계가 읽은 뒤에야 이해됨 | 유사 내용을 묶어 이름을 붙이고, 비교는 같은 기준의 As-Is/To-Be 열로 정렬한다. | p.32–33 |
| 정렬 | 제목·본문·표의 시작선이 어긋나거나 박스 간격이 불규칙함 | 공통 기준선과 간격 단위를 정하고 같은 수준의 요소를 맞춘다. | p.31 |
| 여백·밀도 | 내용끼리 붙어 구분이 안 되거나 작은 글로 과밀하게 채움 | 관련 항목은 묶고 다른 항목은 벌린다. 부차적 세부를 부록으로 옮기거나 페이지를 나눈다. | p.30–31 |
| 글꼴 | 페이지별 제목·본문 패턴이 다르거나 여러 강조 수단이 경쟁함 | 제목·핵심·본문·주석의 스타일을 통일하고 굵기·크기 중심으로 강조를 줄인다. | p.54 |
| 색 | 같은 의미가 다른 색이거나 모든 항목이 강한 색으로 강조됨 | 주색·보조색·강조색의 역할을 정하고 같은 의미에 같은 색을 적용한다. | p.55–56 |
| 선·도형 | 선이 내용보다 강하거나 같은 의미의 도형이 제각각임 | 장식적 테두리를 줄이고 연결·구분·강조 목적에 맞는 선과 도형을 통일한다. | p.57–60 |
| 하단 요약 상자 | 빈 공간을 채우거나 본문·결론을 그대로 반복함 | 추가 함의나 다음 페이지로의 연결이 있을 때 사용하고, 핵심 결론은 헤드라인에 둔다. | p.34 |
| 이미지 | 핵심과 무관하거나 크롭 때문에 의미가 사라짐 | 설명에 필요한 부분을 중심으로 배치하고 불필요한 배경·장식은 줄인다. | p.72–74 |

**AI 적용 보완**

- “그래프는 왼쪽, 글은 오른쪽”, “하단이 무거운 구도”는 가능한 배치 예시다. 읽기 흐름과 기존 양식에 맞는 다른 구성도 인정한다.
- 사진의 원근 때문에 생긴 기울어짐과 문서 자체의 정렬 오류를 구별한다.
- 대칭과 같은 줄 길이를 만들기 위해 의미 없는 말을 추가하거나 중요한 조건을 삭제하지 않는다.
- 강한 색 자체를 오류로 판정하지 않는다. 브랜드·경고·데이터 구분의 목적과 실제 가독성을 본다.
- 연한 파스텔·얇은 선이 화면이나 인쇄에서 사라지면 진하게 조정한다. 색만으로 구분하지 말고 이름·기호·선 모양을 함께 쓴다.
- 점선은 예측·예정·가상 등의 의미를 암시할 수 있다. 확인되지 않은 상태를 선 모양으로 새로 부여하지 않는다.
- As-Is/To-Be는 같은 비교 항목을 같은 행에 놓고, 실제 현황과 제안·목표를 명확히 구별한다.
- 보고용 사진은 증거가 될 수 있다. 크롭·톤 조정으로 결함이나 맥락이 숨겨질 수 있으면 원본과 수정 목적을 함께 남긴다.

## 3. 표는 읽고 비교하기 쉽게 정리한다

**교재 기반: p.61–64**

- 정확한 값, 여러 항목의 조건, 계산 결과를 함께 확인해야 한다면 표를 유지한다.
- 표의 머리행·구분열과 본문을 시각적으로 구분하고, 불필요한 내부 격자는 줄인다.
- 셀 안쪽 여백과 같은 종류의 행 높이를 일정하게 한다. 긴 설명에 필요한 높이는 별도로 확보한다.
- 문장형 셀은 왼쪽·위쪽 정렬을 기본으로 하며, 숫자는 오른쪽 정렬해 크기를 비교하기 쉽게 한다.
- 행·열의 제목이 여러 줄로 갈라져 뜻이 흐려지면 열 너비와 머리글 표현을 함께 조정한다.

**AI 적용 보완**

- 숫자는 단위, 소수 자릿수, 천 단위 구분, 음수 표기, 기준 기간을 맞춘다. 원본 정밀도를 임의로 바꾸지 않는다.
- 금액·비율·증감률의 기준이 다르면 머리글이나 주석에 적는다. `%`와 `%p`를 바꾸지 않는다.
- 빈칸·0·해당 없음·미집계는 서로 다르다. 표를 단순화하며 같은 의미로 합치지 않는다.
- 행 높이·열 너비를 모두 같게 만드는 것이 목표는 아니다. 내용 길이와 비교 목적을 기준으로 정한다.
- 표가 길어지면 핵심 비교를 본문에 두고 상세 표는 부록으로 제안한다. 원본 값을 삭제했다고 숨기지 않는다.
- 합계·구성비·증감 등 계산 검증은 원자료를 읽을 수 있을 때 수행하며, 이미지에 보이지 않는 항목을 가정하지 않는다.

## 4. 그래프는 전달할 관계에 맞춰 선택한다

**교재 기반**: 관계는 그래프로, 개별 값의 확인은 표로 보여준다(p.61, 65). 긴 이름·순위는 가로막대(p.67), 선의 표현은 선 그래프 사례(p.68), 서로 다른 지표는 조합 그래프(p.69), 여러 평가항목은 방사형(p.70), 구성비는 원·도넛(p.71)을 예시로 제시한다. 선 그래프를 시간·연속 순서에 맞춰 선택하는 조건은 아래 AI 보완에서 명확히 한다.

**AI 적용 보완: 아래 조건으로 최종 선택한다.**

| 전달할 내용 | 우선 검토할 표현 | 확인 조건 |
|---|---|---|
| 항목의 크기·순위 | 가로 또는 세로 막대 | 같은 단위·기준, 의미 있는 정렬, 범주별 동일 기준선 |
| 시간에 따른 변화 | 선 | 날짜·간격·누락 구간, 실적과 전망의 구별 |
| 전후 변화 | 나란한 막대 또는 전후 점 비교 | 비교 대상과 기간이 대응하고 두 값의 기준이 같음 |
| 전체의 구성비 | 소수 항목의 원·도넛, 누적 막대 | 같은 전체의 상호 배타적 항목, 합계와 분모 확인 |
| 세부 수치·복합 조건 | 표 | 단위·자릿수·머리글·행 대응이 명확함 |
| 여러 평가항목 | 묶음 막대·점 비교, 필요 시 방사형 | 척도·방향이 같으며 항목 순서와 면적이 평가를 오도하지 않음 |
| 서로 다른 두 지표 | 같은 시간축의 분리 그래프, 필요 시 이중축 | 축별 단위·범위·계열 대응이 명시됨 |

### 그래프 정확성 검수

**AI 적용 보완. 교재의 미적 조언보다 데이터 의미 보존을 우선한다.**

1. 막대 길이로 크기를 비교할 때는 0 기준선을 기본으로 한다. 작은 차이를 보여야 하면 차이값·점 비교를 검토한다.
2. 축을 자르는 예외가 필요하면 시작점과 절단 사실을 명확히 표시한다. 축을 숨겨 차이를 크게 보이게 만들지 않는다.
3. 선 그래프의 0 이외 시작점은 가능하나 범위·단위와 변화 폭을 읽을 수 있어야 한다. 비교 패널은 같은 기준을 쓴다.
4. 축·눈금선은 읽는 데 불필요할 때만 줄인다. 직접 수치 표기를 쓰더라도 단위·기간·기준선은 남긴다.
5. 범주가 단순한 회사명·제품명일 뿐이면 선으로 잇기 전에 연속성·순서 의미가 있는지 확인한다.
6. 실제 관측점 사이를 보기 좋게 곡선으로 만들거나, 마지막 구간을 임의로 점선 처리하지 않는다.
7. 이중축을 쓰면 두 단위와 대응 계열을 표시한다. 두 선을 겹치거나 벌리기 위한 축 조절로 관계를 암시하지 않는다.
8. 구성비 그래프는 분모·합계·반올림을 확인한다. 중복 응답, 음수, 서로 다른 전체는 원그래프로 묶지 않는다.
9. 강조색·레이블은 판단에 필요한 핵심에 사용한다. 강조한 항목에 불리한 데이터·범례·조건도 보존한다.
10. 3차원·원근·과도한 분리·부풀린 아이콘은 크기 비교를 흐릴 수 있으므로 평면 표현을 우선 검토한다.
11. 차트 숫자, 본문 주장, 헤드라인의 방향이 일치하는지 확인한다. 근거 없는 인과관계나 전망을 새로 만들지 않는다.

### 교재 조언 중 조건부로 적용할 부분

- **p.65·68 축 범위 조절과 축 삭제**: 차이 강조만을 목적으로 따라 하지 않는다. p.65 실제 예시는 150부터 시작한 막대축을 수정본에서 숨겨 차이가 과장될 수 있다.
- **p.68 선 스타일**: 실제 예시는 회사별 범주를 선으로 잇고 마지막 구간을 점선으로 표현한다. 새로운 문서에서는 데이터의 순서와 상태가 이를 뒷받침해야 한다.
- **p.69 이중축 범위 조절**: 보기 좋게 분리하는 것보다 두 지표의 해석 가능성을 우선한다. 필요하면 같은 시간축의 두 패널로 나눈다.
- **p.70 방사형·p.71 도넛**: 세련된 모양 자체가 선택 이유가 되지 않는다. 정확한 비교가 더 중요하면 막대·점·표를 제안한다.
- **p.72 이미지 파일 설명**: PNG라고 모두 투명하지 않으며, 픽셀 수만으로 선명도를 보장하지 않는다. 실제 투명도·확대 상태·원본 품질을 확인한다.

## 5. 수치 예시와 검수 결과의 사용법

- 교재의 12–15줄·여백 약 30%(p.31), 글꼴 2–3개·예시 20/16pt(p.54), 3색(p.55), 내부선 0.25–0.5pt(p.57)는 **권장 예시**다.
- 원그래프 6개 이내·도넛 3개 이하(p.71)도 제한적 예시다. 항목이 적어도 의미가 맞지 않으면 다른 표현을 쓴다.

- 우선순위는 **수치·의미 왜곡 / 읽기 불가 / 구조 이해 방해 / 일관성 / 취향에 따른 개선** 순으로 판단한다.
