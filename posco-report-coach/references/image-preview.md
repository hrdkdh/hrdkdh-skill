# 개선 시안 이미지

교재 p.22–37, 54–74의 구조화·시각화 원칙을 AI 시안 제작에 확장한다. 이미지 생성 자체는 교재의 기능이 아니며, 내용 검증을 마친 문안을 시각적으로 보여 주는 보완 수단이다.

## 언제 시안을 만드는가

- 사용자가 개선된 모습을 이미지로 요청하면 제작한다. 재구성 방향이 글로만 설명하기 어려울 때도 필요한 대표 페이지를 시안으로 제시할 수 있다.
- 단순 오탈자 수정이나 소수 문장 교정에는 이미지 제작을 덧붙이지 않는다. 여러 페이지가 있다면 변화가 잘 드러나는 페이지를 우선 고르며 전체 재제작을 임의로 확대하지 않는다.
- 별도 요청이 없으면 원본의 문서 종류·화면 비율·필수 브랜드 양식을 유지한다. 크기가 불명확한 이미지에서 A4나 16:9라고 단정하지 말고 시안 가정을 밝힌다.

## 먼저 문안을 고정한다

1. 해당 페이지의 핵심 메시지와 근거를 정리한다. 본문이 지지하지 못하는 제목을 더 설득력 있게 꾸미지 않는다.
2. `제목 / 헤드라인 / 본문 / 표·그래프 데이터 / 단위·기간·출처 / 확인 필요 표시`를 별도 텍스트로 확보한다.
3. 문구와 수치가 원문에서 온 것인지, 원문 값으로 계산한 것인지, 새로운 제안인지 구별한다. 실제 데이터가 없는 그래프는 그리지 않거나 `배치 예시·데이터 미입력`으로 명확히 표시한다.
4. 헤드라인을 읽고 근거로 이동하는 시선 순서를 정한다. 구조가 같은 항목은 같은 모양·간격·색 의미를 사용한다.

## 사용 가능한 도구에 맞춰 제작한다

- **생성형 이미지 시안·원본 이미지 편집**: 환경의 이미지 생성/편집 도구를 사용한다. 원본을 먼저 확인하고 참조 이미지로 전달하며, 고정할 문구·수치·비율과 바꿀 배치를 명시한다. 도구 자체의 사용 지침을 따른다.
- **정확한 글자·데이터가 중요한 문서/도표**: 사용 가능한 문서·슬라이드·HTML/SVG·차트 도구로 작성하고 PNG 등으로 렌더링하면 정확한 활자와 수치를 보존하기 좋다. 편집 가능한 원본과 미리보기 이미지를 함께 제공할 수 있다. 기존 이미지를 실제로 편집하는 요청은 이미지 편집 도구의 규칙을 따른다.
- **생성 도구는 없고 렌더링은 가능**: 실제 렌더링으로 미리보기를 만든다. 편집 파일만 만들고 이미지까지 만들었다고 주장하지 않는다.
- **둘 다 불가**: 고정 문안과 구역별 배치 명세를 제공하고, 이 환경에서는 이미지 파일을 생성하지 못했다고 명시한다. 이미지 프롬프트만으로 제작이 완료됐다고 말하지 않는다.

이미지 도구에 전달할 명세 예:

```text
목적: 경영진 검토용 보고서 1쪽 개선 시안
형식: 원본과 동일한 비율, 실제 문서처럼 평면 배치
필수 양식: 사용자가 제공한 회사 규정과 고정 요소
내용: 아래 확정 문구와 숫자를 그대로 사용
배치: 상단 결론, 중앙 근거/비교, 하단 실행 조건과 확인사항
시각 원칙: 일정한 정렬선과 간격, 제목/본문 위계, 제한된 강조색
데이터: 제공 값만 사용하고 축·단위·기간·출처를 보존
금지: 새로운 수치/로고/승인 표시, 장식용 가짜 그래프, 의미가 바뀌는 생략
고정 문구 및 데이터: (현재 작업에서 확인한 내용을 입력)
```

## 결과 이미지를 실제로 검사한다

- 생성/렌더링 후 다시 열어 제목·수치·날짜·단위·출처·부정 표현·조건을 고정 문안과 대조한다.
- 한글 오탈자, 누락, 잘림, 겹침, 표의 행/열 대응, 범례/축 불일치, 낮은 대비를 확인한다.
- 생성형 이미지의 한글이나 숫자가 틀리면 수정하거나 정확한 문서 렌더링으로 바꾼다. 끝내 해결하지 못하면 `배치 참고용 시안—문구 검증 미완료`로 한계를 표시하고 정확한 문안을 별도로 제공한다. 수치가 틀린 시안을 최종 보고서로 전달하지 않는다.
- 재시도는 필요한 오류 수정에 한정한다. 반복 실패 시 현재 한계와 대체 산출물을 설명한다.
- 비교 이미지를 제공한다면 전후 배율을 맞춰 구조 변화가 보이게 한다. 원본·개선안을 명확히 구분한다.

## 전달

실제 이미지와 변경 이유 2~3개, 수정된 정확한 문안, 필요시 편집 가능한 파일을 제공한다. 이미지 시안과 편집 가능한 보고서를 구분한다. 시안만 제작한 경우 실제 원본 문서가 수정되었다고 말하지 않는다.
